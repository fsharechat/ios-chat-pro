# 玻璃态消息输入面板

2026-11-14。对应设计：`docs/superpowers/specs/2026-11-14-liquid-glass-message-composer-design.md`。

## 实现

- 独立常驻＋圆按钮、悬浮玻璃胶囊；正文非空时尾部显示↑，空正文显示语音入口。更多面板补充「语音消息」，允许保留文字时切到录音。
- 现有文本、@、Emoji、相册图片/视频、拍摄图片/视频、文件、位置、单聊音视频通话回调保留。群聊仍不显示通话入口。
- `ComposerGlassBackgroundView` 使用系统材质模糊、高光边与独立阴影；浅深色及减少透明度/增强对比度动态响应。`ComposerBottomProtectionView` 承托底部安全区。当前没有使用新 SDK 的 UIGlassEffect。
- 列表延伸到悬浮栏后方，以底部 inset 使最新消息完整可见。透明间隙和装饰层不消费消息触摸。
- `ComposerState` 管理模式和面板。键盘通知转换到当前视图坐标、排除浮动键盘；同一 spacer 采用 `max(键盘高度, 面板高度)`，不双重占位。切回键盘时保留短期占位并使用转移ID丢弃旧回调。布局变化保持底部跟随或已有历史位置。
- 更多面板支持内部滚动、图标和标题整体点击、VoiceOver激活。Emoji改为按页逐行布局，保留全部表情和退格。
- `ComposerMentions` 将身份绑定到富文本范围；支持同名成员区分、部分选区/退格整块删除、@所有人移除后恢复个人收件人、切面板保留元数据。手工粘贴普通@文字不会制造收件人。
- `VoiceRecordingController` 统一麦克风权限、上滑取消/回滑、时长提示、60秒封顶、系统中断/后台/离页取消。一次按压只消费一次发送结果。保留AMR转换、M4A回退与本地播放缓存，清理未发送临时文件。
- Xcode工程通过脚本重新生成。先将`project.yml`与已有Info.plist版本对齐，避免生成工程时版本回退；本次归档版本统一为2.0.20/20020。

在可用的Xcode/设备环境按设计文档回归，重点检查：

1. 小屏/大字体/横屏的多行胶囊与表情排布。
2. 键盘、表情、更多快速切换；外接/浮动键盘；历史位置和最新消息可见性。
3. 录音首次授权、拒绝、短录音、上滑/回滑、60秒超时、中断/后台，无误发或重复发送。
4. @插入/删除、相册视频、拍摄视频、文件、位置及单聊通话。
5. 深浅色、减少透明度/动态效果、VoiceOver，消息经过玻璃后的可读性及滚动性能。
